# NeuroTrace 比赛提交填写指南

以下内容按当前代码、演示页面和验证结果撰写，可直接粘贴。不要把 20 篇 / 805 条机器候选写成已经完成的 Gold 数据。

## 项目背景

科研 AI 已经很会总结单篇论文，但研究写作中更危险的错误往往不是凭空编造，而是把分别成立、各有条件的真实发现，压缩成跨对象、跨任务、跨材料和跨加工阶段的统一结论。长上下文能提供更多文本，却不会自动判断每篇证据究竟能支持到哪里。NeuroTrace 以 ERP/EEG 隐喻加工研究中的真实写作场景为切口，在论断进入论文前，先把它编译成可核验的证据边界。

## 核心功能

1. 将候选论断拆成研究对象、语境、隐喻类型、任务、ERP 成分、加工阶段和效应方向 7 个维度。
2. 检测绝对化、跨类型泛化、N400 方向错误、阶段遗漏、任务与情绪边界遗漏等风险。
3. 区分有条件支持、直接限定/反例和非直接边界证据，防止“重要论文”被误写成“直接支持”。
4. 以人工审核作为硬门控；未通过的证据不能进入安全结论。
5. 生成保留真实边界的安全改写，并导出含页码、图号、审核记录和 PDF SHA256 的 Markdown、JSON、CSV Evidence Pack。

## 应用价值

NeuroTrace 把科研写作的质量控制从“生成后凭感觉检查”，前移为“写作前验证证据边界”。研究者可以更快发现过度概括、方向误写和条件遗漏；导师、审稿人和团队成员可以沿页码、图号和文件哈希复核论断来源。当前 MVP 用一个窄而真实的 ERP/EEG 场景证明了从论断审计、人工门控到可追溯导出的完整闭环，后续可扩展到更多论文与研究领域。

## 使用说明

1. 安装 Python 3.9 或更高版本。
2. 在项目目录执行 `pip install -r requirements.txt`。
3. 将 `config.local.example.json` 复制为 `config.local.json`；如需本地 PDF 预览，填写 Zotero PDF 目录。
4. 执行 `streamlit run app.py`，在浏览器打开显示的本地地址。
5. 点击“编译证据边界”，审核 Tang、Yao、Baiocco 三张证据卡。
6. 全部通过人工门控后查看安全改写，并下载 Markdown、JSON 或 CSV Evidence Pack。

黄金演示路径完全离线，不需要 API Key，也不会上传论文内容。
