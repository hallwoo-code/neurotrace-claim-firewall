# NeuroTrace 提交页可粘贴文案

## 项目名称

NeuroTrace：ERP/EEG 科研论断防火墙

## 一句话介绍

在科研论断进入论文前，把它编译成可核验的证据边界，阻止真实论文被写成范围过大的结论。

## 解决的问题

科研 AI 已经很会总结单篇论文，但研究写作中更危险的错误往往不是凭空编造，而是把分别成立、各有条件的真实发现压缩成一个跨对象、跨任务、跨材料和跨加工阶段的统一结论。长上下文能提供更多文本，却不会自动判断每篇证据究竟能支持到哪里。

NeuroTrace 以一句真实的 ERP/EEG 隐喻加工论断为例：支持性语境会跨隐喻类型稳定促进隐喻理解，并体现为 N400 波幅降低。系统把论断拆为研究对象、语境、隐喻类型、任务、ERP 成分、加工阶段和效应方向，再用三篇角色不同的论文检查其引用边界。

## 核心方案

1. 编译候选论断的七个可核验维度。
2. 识别绝对化、跨类型泛化、N400 方向错误、阶段遗漏和任务/情绪边界遗漏。
3. 区分有条件支持、直接限定/反例和非直接边界证据。
4. 通过人工审核门控决定证据能否进入 Evidence Pack。
5. 生成安全改写，并导出带页码、图号、审核记录和 PDF 哈希的 Markdown、JSON、CSV 证据包。

## 创新点

- 从“生成更流畅的答案”转向“限制一句话究竟能写到哪里”。
- 将证据重要性、证据角色和是否直接检验显式分开。
- 人工审核是导出的硬门控，而不是装饰性确认。
- 用条件、时间窗、效应方向、页码、图号和哈希构成可复核的最小证据单元。
- 黄金路径完全离线、确定性、可复现，不依赖网络或模型随机输出。

## 技术实现

Python、Streamlit、结构化 JSON 证据记录、确定性论断审计规则、人工审核门控、Markdown/JSON/CSV 导出、SHA256 源文件完整性校验，以及 pytest 自动化测试。比赛黄金路径不需要 API Key，不上传论文内容。

## 当前范围

当前 MVP 严格覆盖 3 篇黄金论文和 1 条黄金论断，用于证明“论断边界审计”这一核心闭环，不是通用 RAG 或开放科研问答系统。项目另保留一个默认隐藏的个人语料审核工具，可读取 20 篇 seed paper 的机器候选，但这些候选在人工处理前不被称为 Gold，也不属于比赛演示路径。

## 验证结果

- 三篇黄金证据均经人工审核进入 Evidence Pack。
- 三篇源 PDF 的 SHA256 与预期值一致。
- Markdown、JSON、CSV 三种证据包均可生成和回读。
- 21 项自动化测试通过。

## 隐私与合规

公开项目不包含 PDF、API Key、本机配置、隐私数据或模型缓存。赛前研究选题、三篇论文和旧解析经验，以及赛期新增的核心功能，均在披露文档中区分说明。
