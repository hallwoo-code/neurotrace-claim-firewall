# NeuroTrace 录屏交接清单

## 推荐成片

- 优先录制 3 分钟版本，最长不要超过比赛平台限制。
- 画面使用 16:9，建议 1920×1080；浏览器缩放保持 100%。
- 只展示首页，不打开侧栏，不进入 `/证据审核`。
- 不展示 Zotero、本机文件路径、终端历史、Downloads 或 API 配置。

## 录制前 10 分钟

1. 关闭通知、聊天窗口和无关标签页。
2. 在项目目录运行 `python -m pytest -q`，确认 21 项测试通过。
3. 运行 `streamlit run app.py`，打开 `http://localhost:8501`。
4. 点击“恢复演示”，确认首页顶部显示“3 篇锁定论文 / 1 条黄金论断 / HITL”。
5. 先静音试录 20 秒，确认文字清晰、页面不卡顿、鼠标没有遮住正文。

## 3 分钟镜头顺序

| 时间 | 画面 | 必说信息 |
|---|---|---|
| 0:00–0:30 | 黄金论断与“编译证据边界”按钮 | 风险不是编造，而是把真实论文写过头 |
| 0:30–1:05 | 过度概括结论、5 个风险、7 个维度 | 长上下文不会自动建立引用边界 |
| 1:05–2:05 | Tang、Yao、Baiocco 三张证据卡 | 有条件支持、直接限定、非直接边界证据 |
| 2:05–2:35 | 三条审核设为 approve | 未通过人工门控的证据不能导出 |
| 2:35–3:00 | 安全改写与 Evidence Pack 下载 | 页码、图号、审核记录和 PDF 哈希可追溯 |

完整逐字话术见 `docs/DEMO_SCRIPT.md`。

## 录制动作约束

- 点击前先停半秒，点击后等待页面稳定再说下一句。
- 不逐字读完所有证据，只讲每篇论文承担的不同角色。
- Baiocco 即使通过也必须指明仍是 `boundary_evidence`。
- 只下载一种格式即可；另外两个按钮用鼠标指一下。
- 如果说错一句，停两秒后从该段重新开始，后期直接剪掉停顿。

## 导出与自检

- 导出 MP4；确认开头不是黑屏，结尾没有多余桌面画面。
- 从头到尾播放一次，确认声音、鼠标、文字和下载动作都可辨认。
- 文件名建议：`NeuroTrace_Demo_3min.mp4`。
- 另保留一份原始录屏，避免平台转码失败后无法重导。
